# Проект созданный по макету интернет-магазина мебели Avion

## Проект
Одностраничный лендинг интернет-магазина мебели с адаптированной вёрсткой под макет:

- Семантическая структура (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- Блок hero с промо-баннером и кнопкой «View collection».
- Блок преимуществ «What makes our brand different».
- Секция товаров **New ceramics** и **Our popular products**.
- Форма подписки «Join the club and get the benefits».
- Блок «From a studio in London to a global brand…».
- Футер с навигацией и иконками соцсетей.

## Стек
- **HTML5**
- **CSS3**
